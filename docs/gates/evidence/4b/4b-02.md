# 4B-02 — macOS runtime V1 evidence

## Result

V1 passed on both hosted architectures at commit
[`78246bc`](https://github.com/zahidzta/zownload_application/commit/78246bcd820b696374b023610162eb1930bd30e3).
The [Gate 4B macOS runtime workflow](https://github.com/zahidzta/zownload_application/actions/runs/43355603828)
and [Foundation CI](https://github.com/zahidzta/zownload_application/actions/runs/43355603983)
completed successfully. The `macos-15` arm64 and `macos-15-intel` x86_64
jobs each built and exercised their native engine. Foundation, Linux, and
Android jobs passed; `windows-install-review` was skipped by its workflow
conditions.

workflow also pinned Node 24.22.0, npm 11.19.1, and Rust 1.99.1.

## Verification

On each macOS runner, CI ran the pinned engine build/verification script,
contract check, frontend build, UI tests, Rust formatting, and Rust tests with
the real staged engine enabled. Each architecture reported 87 Rust unit tests
passing. The architecture-specific name/resource test, verified app-data
bootstrap and reopen tests, updated-engine refresh test, and real pinned-engine
health check passed. The Unix process-tree integration test
`timeout_and_shutdown_stop_the_complete_engine_process_group` passed on both
architectures. The foundation run's Linux checks and shared Windows foundation
checks also passed.

Local Windows verification passed `cargo test` (91 unit tests and applicable
integration tests), `cargo fmt --check`, `npm run check:contracts`,
`npm run build`, and `npm run test:ui` (13 files, 62 tests). The source lock
verification, macOS build-script shell syntax check, Tauri overlay JSON parse,
and `git diff --check` passed.

This evidence covers the macOS runtime task only. DMG/updater packaging is
4B-03; minimum-OS installation, Gatekeeper, and native download/update review
remain in 4B-04.
