# Gate 5A-04 — Android FFmpeg build evidence

Completed 2026-11-23. The pinned FFmpeg 8.1.3 source and detached signature
were verified before extraction. LAME and zlib were built from the locked
sources, then statically linked into FFmpeg/ffprobe for `arm64-v8a`, Android
API 24.

The recipe is [build-ffmpeg.sh](../../../../scripts/gate-5a/build-ffmpeg.sh).
It uses Ubuntu 24.04 x86_64, Corretto 21.0.11.10.1, Android command-line
tools 22.0 (build 15859902), NDK 30.0.16248370, Android API 24, NDK Clang
21.0.0, GNU Make 4.3, and host GCC 13.3.0. Corretto's archive was checked
against `5b4dc8817df13f88f9bfc434e5d018adb535889ff2fe0ccf758bcebcc216f394`;
the Android command-line tools archive was checked against
`4e4c464f145a7512b57d088ac6c278c03c9eea610886b35a5e0804e74eedf583`.

LAME was built static with its decoder and frontend disabled; the build
confirmed `HAVE_MPGLIB` is absent. zlib was built static. FFmpeg's configure
arguments are generated by the recipe and captured in the ignored local
`ffmpeg-configure-args.txt`. They select a static GPL-2.0-or-later build,
disable nonfree and version-3 components, start from `--disable-everything`,
and explicitly enable only the documented codecs, formats, filters, and
protocols. `aresample`, the MP4 muxer, and `wrapped_avframe` are enabled for
the exercised MP3/MP4 paths. Network support, autodetection, x264, x265, and
all unlisted features remain disabled. The recipe builds `ffmpeg ffprobe`
with `make -j2 V=1` and checks generated feature macros and dynamic
dependencies.

## Runtime verification and limits

`powershell -NoProfile -File scripts/gate-5a/verify.ps1 -Case ffmpeg` passed.
The [device smoke script](../../../../scripts/gate-5a/ffmpeg-device-smoke.sh)
passed FFmpeg/ffprobe version checks, an MP3 encode/probe, an MP4 encode and
remux/probe, and the absence of x264/x265 encoders on Android emulator
`sdk_gphone16k_x86_64` (x86_64, API 37). The arm64 binaries ran through the
emulator's native translation. This verifies runtime compatibility in that
emulator; physical `arm64-v8a` device proof remains part of task 5A-09.
