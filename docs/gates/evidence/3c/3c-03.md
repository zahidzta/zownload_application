# Gate 3C-03 — installed NSIS/MSI upgrade review

V2 evidence is **pending**; the controlled NSIS update has failed twice, so neither installer format is accepted yet. The `Windows installed upgrade review` workflow builds older and candidate packages from explicit source refs, then runs clean install, launch, same-format updater, relaunch/version, and uninstall scenarios on an isolated `windows-latest` runner. It serves signed local updater metadata and checks that NSIS requests the NSIS package and MSI requests the MSI package. No owner installation is used.

## Preliminary NSIS findings

- Run [41291930395](https://github.com/zahidzta/zownload_application/actions/runs/41291930395) (`85b2a40`) and [41295033138](https://github.com/zahidzta/zownload_application/actions/runs/41295033138) (`79cc005`) both built the previous and candidate NSIS/MSI pairs and passed package-signature and tamper-rejection checks.
- In each run, the installed `0.0.0` app fetched the candidate `Zownload_0.0.1_x64-setup.exe`, then the installed registry entry and executable remained at version `0.0.0` after the 120-second wait. The tracked old app process had exited. The script stopped at NSIS, before testing the MSI updater scenario.
- `79cc005` adds an updater-only, bounded NSIS preinstall wait based on the Restart Manager race described in [Tauri issue #16277](https://github.com/tauri-apps/tauri/issues/16277). It did not change the observed outcome. The root cause is not confirmed; the hook is not considered a fix without a passing rerun.
- [FR-75](../../../../PROJECT.md#fr-75) calls for a “New version available” message with a direct download link if a package updater proves unreliable. This fallback has **not** been implemented; owner review is required before changing the app’s update behavior.

The formal V2 run remains `previous_ref=main`, `candidate_ref=task-3c-02-03`, `previous_version=0.0.0`, and `candidate_version=0.0.1`. A passing run must record clean install, launch/version, matching-format update, relaunch/version, and uninstall for both NSIS and MSI.
