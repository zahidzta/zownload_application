# Gate 3C-03 — installed NSIS/MSI upgrade review

V2 evidence is **pending**. The `Windows installed upgrade review` workflow builds older and candidate packages from explicit source refs, then runs clean install, launch, same-format updater, relaunch/version, and uninstall scenarios on an isolated `windows-latest` runner. It serves signed local updater metadata and checks that NSIS requests the NSIS package and MSI requests the MSI package. The task branch invokes it through the existing CI workflow; an owner can also dispatch it manually after merge. No owner installation is used.

Run the workflow with `previous_ref=main`, `candidate_ref=task-3c-02-03`, `previous_version=0.0.0`, and `candidate_version=0.0.1`. Copy the generated V2 report from the workflow artifact into this file after both formats pass.
